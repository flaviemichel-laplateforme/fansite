À propos du site

Pourquoi ce projet

Ce site est avant tout un hommage à Naâman, disparu le 7 février 2025. Je l'ai réalisé dans le cadre de ma formation à La Plateforme, pour mettre en pratique le HTML, le CSS et le JavaScript sur un projet complet. C'est un fan site non officiel, sans but commercial.

Ce que j'ai construit

  • Dix pages : accueil, actualité, réalisations, évènements, photos, vidéos, liens, contact, mentions légales et cette page.
  • Un menu avec sous-menus, qui devient un menu burger sur mobile.
  • Un formulaire de contact de démonstration.
  • Des contenus vérifiés et sourcés (Wikipédia, presse, sites spécialisés).

Technologies et choix

  • HTML sémantique : un seul h1 par page, article, figure, nav nommés, listes et dates balisées.
  • CSS : Flexbox, variables CSS, media queries à 800 px et 600 px.
  • JavaScript sans bibliothèque : ouverture du menu, page courante, confirmation du formulaire.
  • Accessibilité : lien d'évitement, focus visible, textes alternatifs, contrastes.
  • Performance et SEO : images en chargement différé, balises description et Open Graph, vidéos en mode sans cookies.

La principale difficulté : le CSS

Ma feuille de style avait grossi jusqu'à environ 1 140 lignes, avec des règles en double, des sélecteurs qui ne correspondaient plus au HTML et plusieurs media queries qui se contredisaient. Je l'ai réécrite par sections, avec des variables pour les couleurs, des classes aux noms explicites et un seul jeu de règles responsive. J'en retiens qu'il vaut mieux structurer le CSS dès le départ que le nettoyer à la fin.

Limites assumées

  • Le formulaire de contact est une démonstration : aucun message n'est envoyé.
  • Certaines dates de concerts n'ont pas pu être confirmées et sont indiquées comme telles.
  • Les vidéos et la musique viennent de YouTube et de Spotify, les photos de leurs auteurs.

Code source

Le code est disponible sur GitHub. Les sources des informations sont détaillées dans les mentions légales.
